# Guia de Contribuição

Obrigado por querer contribuir com o Padroniza Excel Jet! 🎉

## Como Contribuir

### 1. Fork o Repositório

```bash
git clone https://github.com/seu-usuario/padroniza-excel-jet.git
cd padroniza-excel-jet
```

### 2. Crie uma Branch

```bash
git checkout -b feature/sua-feature
# ou
git checkout -b fix/seu-bugfix
```

### 3. Faça suas Alterações

- Escreva código limpo e bem documentado
- Mantenha o estilo do projeto
- Adicione testes quando possível

### 4. Commit

```bash
git commit -m "Descrição clara da mudança"
```

### 5. Push e Pull Request

```bash
git push origin feature/sua-feature
```

Abra um Pull Request no GitHub com uma descrição clara.

## Padrões de Código

### Python (Backend)

- PEP 8 compliant
- Type hints obrigatórios
- Docstrings para funções públicas

### TypeScript (Frontend)

- ESLint strict
- Componentes funcionais com Hooks
- Nomes descritivos de variáveis

## Reportar Issues

Encontre um bug? Crie uma issue com:
- Descrição clara
- Passos para reproduzir
- Comportamento esperado vs atual
- Screenshots se aplicável
